# My Portfolio

A Flutter web portfolio website showcasing my projects and experience as a Flutter developer.

## Features

- Responsive design for mobile, tablet, and desktop
- Project showcase
- Experience timeline
- About me section
- Contact form
- Social media links

## Built With

- Flutter
- Dart
- Flutter Web

## Deploy

This project is automatically deployed to GitHub Pages on every push to the main branch.

## Getting Started

```bash
flutter pub get
flutter run -d chrome  # or web platform
```
